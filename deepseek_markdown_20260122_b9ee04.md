# Performance Appraisal Progress Dashboard

A comprehensive web-based dashboard for tracking performance objectives, key action points, and KPIs.

## Features
- 📊 Real-time progress tracking
- 📝 Add/edit objectives and tasks
- 📎 Attach evidence files
- 📅 Set reminders and due dates
- 📄 Export to PDF
- 💾 Auto-save to browser storage
- 📱 Responsive design

## How to Use
1. Open `index.html` in your browser
2. Add your objectives and tasks
3. Track progress with visual indicators
4. Attach supporting documents
5. Export reports as PDF
